Setup needed

The admin panel needs OAuth credentials in assets/config.js:

  1. Create a Discord application at discord.com/developers/applications. Copy the Client ID into discordClientId, then add this redirect URI to the app:
  2. Create a Google OAuth Web application client at console.cloud.google.com/apis/credentials. Copy the Client ID into googleClientId, then add this authorized JavaScript origin:
  3. Enable Developer Mode in Discord (Settings → Advanced), right-click your name → Copy User ID, and put it in adminDiscordIds.

The panel writes to your own Drive folders, so only your Google account can upload or edit. Discord is the sign-in gate.
